# 🎬 NazMovies — منصة أفلام ومسلسلات (نمط Netflix)

منصة بث وتحميل متكاملة: واجهة داكنة ثنائية اللغة (عربي RTL / إنجليزي LTR)، لوحة تحكم سرية، تتبع مشاهدات وتحميلات، وتحليلات جغرافية للزوار.

## التشغيل

```bash
cd nazmovies
npm install        # مرة واحدة
node server.js     # يعمل على http://localhost:3000
```

قاعدة البيانات SQLite تُنشأ تلقائياً في `data/nazmovies.db` مع كتالوج تجريبي (8 أعمال + إحصائيات 30 يوماً). لحذف الكتالوج التجريبي والبدء من الصفر: احذف ملف قاعدة البيانات ثم أعد التشغيل.

## 🔐 الوصول السري للوحة التحكم

1. افتح المسار السري: **`/adminjo`** (مثال: `https://yoursite.com/adminjo`).
2. أدخل الرقم السري: **9770327** — يُتحقق منه على الخادم فقط ولا يظهر في أي كود متصفح.
3. الجلسة تدوم **30 يوماً**. لا يوجد أي رابط أو طريقة أخرى لفتح اللوحة.

## 📱 زر تحميل التطبيق

من لوحة التحكم ← تبويب «تطبيق الموقع»: ضع رابط التحميل، ونص الزر، وفعّل المفتاح —
يظهر زر عائم في كل صفحات الموقع ويتحدّث فورياً عند أي تعديل.

## أقسام لوحة التحكم

| القسم | الوظيفة |
|---|---|
| 📊 نظرة عامة | زيارات اليوم/الأسبوع/الشهر، مخطط 30 يوماً، **التوزيع الجغرافي للزوار حسب الدولة**، الأكثر مشاهدة وتحميلاً، التحميلات حسب الجودة |
| 🎬 المحتوى | إضافة/تعديل/حذف أفلام ومسلسلات ومواسم وحلقات — **استيراد تلقائي من TMDB** (بوسترات وقصص وتقييمات بالعربية والإنجليزية) — إدارة **سيرفرات متعددة** (تضمين/MP4) وروابط تحميل بعدة جودات لكل فيلم أو حلقة |
| 📢 الإعلانات | لصق وإدارة سكربتات Popads/Adsterra والبوب أندر مع زر تفعيل/تعطيل — **دون تعديل أي ملف** |
| ⚙️ الإعدادات | اسم الموقع، اللغة الافتراضية، مفتاح TMDB، تغيير الرمز السري |

## مفتاح TMDB (اختياري لكنه مريح)

1. أنشئ حساباً مجانياً على [themoviedb.org](https://www.themoviedb.org) ← Settings ← API ← انسخ **API Key (v3)**.
2. الصقه في: لوحة التحكم ← الإعدادات ← TMDB API key.
3. من تبويب «المحتوى» ابحث باسم أي فيلم/مسلسل واضغط «استيراد» — تُملأ كل البيانات تلقائياً، وتُنشأ المواسم والحلقات للمسلسلات.
4. يبقى عليك فقط لصق روابط السيرفرات والتحميل الخاصة بك.

## ملاحظات تقنية

- **الإعلانات** تُحقن في صفحات الزوار فقط (لا تُحقن في لوحة التحكم) ولا تعمل إلا عند التفعيل.
- **التحليلات الجغرافية**: يُحسب بلد الزائر من عنوان IP عبر ip-api.com مع كاش داخلي؛ العناوين المحلية تُسجَّل «محلي». عند الاستضافة الحقيقية فعّل الترويسة `X-Forwarded-For` من البروكسي (تعمل تلقائياً مع Nginx/Cloudflare).
- سيرفرات البث التجريبية تشغّل فيديوهات عامة (Big Buck Bunny) لإثبات أن المشغّل يعمل — استبدلها بسيرفراتك.
- ⚖️ **تنبيه قانوني**: ارفع فقط محتوى تملكه أو مرخّص لك توزيعه. نشر أفلام محمية بحقوق النشر دون ترخيص يعرّض الموقع للحظر والمساءلة، وشبكات الإعلانات تغلق مثل هذه الحسابات.
